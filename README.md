# 남영훈 · Android Engineer Portfolio

공개 주소: https://nyhoon.github.io/my-portfolio/

빌드 도구나 프레임워크 없이 동작하는 정적 HTML/CSS/JavaScript 포트폴리오입니다. GitHub Pages가 `main` 루트를 배포합니다.

## 구성

- `index.html`: 소개, 경력, 개인 프로젝트, 기술 스택. 기존 경력 내용은 유지합니다.
- `css/portfolio.css`: 밝은 뉴트럴 배경, 녹색 포인트, 반응형 레이아웃과 인쇄 스타일.
- `js/portfolio.js`: 현재 읽는 섹션의 내비게이션 강조. JavaScript가 없어도 링크와 본문은 동작합니다.
- `assets/today-hankki-*.webp`: 실제 오늘한끼 앱 캡처. 예시 재고가 포함된 화면이며 가상 UI가 아닙니다.

## 2026-10-27 업데이트

오늘한끼 Google Play 출시 프로젝트를 Toy projects 맨 위에 추가했습니다. 식재료·표시 기한 관리, 영수증/날짜 OCR, 보유 재료 레시피 연결, 장보기와 요리 후 재고 정리를 소개합니다. iOS 스토어 출시나 OCR 완전 정확도를 주장하지 않습니다.

`ui-ux-pro-max` 검색의 개인 포트폴리오 패턴과 접근성 지침을 참고했습니다. 경력과 프로젝트를 구분하는 편집형 구성, 큰 제목과 얇은 구분선, 명확한 키보드 포커스와 모션 감소 설정을 적용했습니다. 기술 포트폴리오의 가독성을 위해 추천된 장식 서체 대신 기존 Pretendard를 유지했습니다.

로컬 확인: `python3 -m http.server 8770 --bind 127.0.0.1`

검수: 작은 화면에서 가로 넘침·이미지 비율·내비게이션 이동·외부 링크·인쇄 스타일을 확인합니다. 새 다운로드 수나 성과 수치를 임의로 추가하지 않습니다.

### 검수 결과 (2026-10-27)

- 375 / 768 / 1024px 브라우저 폭: 가로 넘침 없음. 기본 데스크톱 폭 1512px도 확인.
- 실제 앱 이미지 2장 로딩 및 원본 9:20 비율 유지 확인.
- 프로젝트 바로가기와 상단 섹션 링크 이동 확인.
- 모션 감소 설정에서 `scroll-behavior: auto`, 인쇄 모드에서 메뉴 숨김·흰 배경 확인.
- 기존 경력 섹션의 텍스트를 이전 커밋과 대조해 동일함을 확인.
- 앵커 대상, 중복 ID, 로컬 애셋, 외부 링크의 `noopener noreferrer`, JS 문법 검사 통과.
- 실물 휴대폰 및 별도 Safari 검수는 미실시.
