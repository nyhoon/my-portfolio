# 남영훈 · Android Engineer Portfolio

공개 주소: https://nyhoon.github.io/my-portfolio/

빌드 도구나 프레임워크 없이 동작하는 정적 HTML/CSS/JavaScript 포트폴리오입니다. GitHub Pages가 `main` 루트를 배포합니다.

## 최종 디자인: A2 이력서형 (2026-10-27)

선택된 A2의 휴대폰 프레임·내부 스크롤·좌우 이력서 구성을 공개 메인에 적용했습니다. A2 적용 당시 본문 문구를 유지했으며, 이후 사용자 제공 경력을 추가했습니다. 오늘한끼·NeoFall은 Toy Projects 안에서 소개하고, 전체 페이지는 뉴트럴 배경과 차콜 포인트를 사용합니다.

- 소개 / 연락처·학력, 회사 정보 / 담당 프로젝트를 구분합니다. 좁은 화면에서는 한 열로 바뀝니다.
- 카드 내부 패딩과 섹션 간격은 4px 간격 체계로 정리합니다. 본문은 데스크톱 15px, 모바일 16px입니다.
- 하단 캡슐 메뉴는 본문과 분리된 공간을 사용해 글자·키보드 포커스를 가리지 않습니다. 각 메뉴 터치 영역은 최소 44px입니다.
- 실제 앱·게임 이미지의 원래 비율을 유지합니다. 홍보용 이미지와 실제 플레이 화면을 캡션으로 구별합니다.
- 키보드 포커스, 본문 건너뛰기, 모션 감소, 인쇄용 전체 문서 표시를 지원합니다.

## 구성

- `index.html`: 소개, 경력, Toy Projects, 기술 스택. 공개 메타데이터와 canonical URL 포함.
- `css/portfolio.css`: 독립적인 최종 A2 스타일, 반응형·인쇄·모션 감소 처리.
- `js/portfolio.js`: 내부 스크롤 진행률, 현재 메뉴 강조, 앵커 및 브라우저 탐색 기록 동기화. JavaScript가 없어도 앵커와 본문은 동작합니다.
- `assets/today-hankki-*.webp`: 예시 재고가 포함된 실제 앱 캡처.
- `assets/neofall-*.webp`: 기존 게임 아이콘, 실제 플레이 캡처, 프로모션 이미지.
- `assets/icons/`: [Lucide](https://github.com/lucide-icons/lucide) SVG와 라이선스.
- `design-previews/`: 이전 비교 시안 보관. B/C/D는 `editorial-base.css`와 `editorial-nav.js`를 사용해 최종 메인의 스타일 변경에 영향받지 않습니다.
- `tests/navigation.test.cjs`: 메뉴 선택, 진행률, 마지막 섹션, 브라우저 기록, 없는 앵커, 홈 복귀 회귀 검사. Node 표준 라이브러리만 사용합니다.

새 다운로드 수나 성과 수치를 추가하지 않았습니다. 오늘한끼는 Google Play 출시를 소개하며 iOS 스토어 출시나 OCR 완전 정확도를 주장하지 않습니다.

## 로컬 확인

```sh
python3 -m http.server 8770 --bind 127.0.0.1
node --check js/portfolio.js
node tests/navigation.test.cjs
```

## 최종 검수 결과 (2026-10-27)

- Chrome 320×812 / 375×812 / 768×1024 / 1024×768 / 812×375 및 기본 데스크톱: 문서·프레임 내부 가로 넘침 없음, 하단 메뉴 최소 44px 확인.
- 다섯 메뉴 이동, 키보드 Enter, 뒤로·앞으로 탐색 시 본문과 메뉴 선택 일치 확인.
- 모든 이미지 로딩, 앵커 대상, 중복 ID, 로컬 애셋, 외부 링크 속성 검사 통과. 기존 비교 시안의 로컬 참조도 검사.
- A2 적용 당시 본문 1,635개 공백 구분 토큰을 선택한 시안과 대조해 동일함을 확인. 이후 삼성전자 경력을 추가했습니다.
- 주요 본문·보조 문구·버튼 대비 5.05:1 이상. 전체 접근성 인증을 뜻하지 않습니다.
- 모션 감소에서 `scroll-behavior: auto`, 인쇄에서 메뉴 숨김·전체 본문 표시 확인.
- JS 문법과 내비게이션 회귀 검사 통과.
- 실물 휴대폰·Safari 및 운영체제별 화면 읽기 도구 검수는 미실시.

## 경력 내용 보완 (2026-10-27)

사용자 제공 삼성전자 임시직/프리랜서 경력(2026.07~2026.10, 4개월)을 경력 목록 맨 위에 추가했습니다. 제조·물류 자동화 앱 개발 및 유지보수, 물류 패킹 ML Kit OCR 인식, WebSocket·블루투스 연동, gRPC 통신을 기재했습니다. 제공되지 않은 부서·직급·기여도·성과·퇴사 사유는 추가하지 않았습니다. 이전 디자인 시안은 당시 비교 기록으로 유지합니다.
