# A형 포트폴리오 · 컴포넌트 3개 시안

비교 페이지: `index.html`.

당시 최종 선택 전 비교용으로 만든 세 시안입니다. 이후 A2가 선택되어 공개 메인에 적용되었습니다. 이 폴더는 비교 기록으로 유지합니다.

| 시안 | 프로필 | 경력 | 메뉴 |
| --- | --- | --- | --- |
| A1 정돈된 앱형 | 프로필과 연락처·학력 패널 | 회사와 담당 프로젝트를 한 카드 묶음으로 | 아이콘 배경으로 선택 표시 |
| A2 이력서형 | 이름 / 연락처의 간결한 좌우 배치 | 회사 정보 / 프로젝트의 두 열. 모바일은 한 열 | 떠 있는 캡슐형 메뉴 |
| A3 매거진형 | 네이비 프로필 밴드 + 밝은 연락처 시트 | 타임라인과 얇은 구분선 | 원형 아이콘 + 코랄 선택 표시 |

## 내용 유지와 배치 변경

- 기존 `../2026-10-27/a.html`의 프로필·경력·프로젝트·기술 문구를 유지했습니다.
- 프로필 상단의 오늘한끼·NeoFall 진입 카드를 Toy Projects 안으로 이동했습니다. 본문의 문구를 삭제하거나 성과 수치를 추가하지 않았습니다.
- 실제 이미지와 스토어 링크도 그대로 유지했습니다.
- 화면 상단 실행 팝업 없이 바로 본문을 보여줍니다. 휴대폰 프레임·내부 스크롤·하단 메뉴는 세 시안 모두 유지합니다.

## 구현과 자료

기존 A의 `legacy-phone.css`, `phone.css`, `phone.js`와 프로젝트 이미지를 재사용합니다. `refinements.css`에서 세 시안의 컴포넌트와 배치를 구분합니다. 패키지·프레임워크 추가는 없습니다.

하단 아이콘은 [Lucide](https://github.com/lucide-icons/lucide)의 원본 SVG이며 라이선스는 `assets/lucide-LICENSE`에 보관했습니다. 비교용 `assets/a*-*.webp`는 실제 브라우저 캡처입니다.

## 검수

- 기존 A와 세 시안의 본문 토큰 대조: 문구 추가/누락 없음. 장식 요소와 비교용 상단 바는 대조에서 제외했습니다.
- 320 / 375 / 768 / 1024px에서 문서와 휴대폰 내부 가로 넘침 없음.
- 기본 데스크톱 폭 1512px에서 프로필·경력·Toy Projects를 각각 캡처·확인했습니다.
- 하단 메뉴의 화면 이동과 선택 표시, 실제 이미지 로딩 확인.
- 비교 페이지의 프로필 / 경력 카드 / Toy Projects 전환과 키보드 조작 확인.
- 일반 문구·버튼에 대한 주요 색상 조합의 대비 확인. 모션 감소에서는 스크롤/전환을 중지합니다.
- 이 비교 시안 단계에서는 실물 휴대폰·Safari 검수를 하지 않았습니다. 최종 A2 적용과 재검수 결과는 루트 README를 참고합니다.
