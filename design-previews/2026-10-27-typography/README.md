# A2 글자 가독성 비교

공개 메인의 글꼴을 바꾸지 않고 두 방향을 비교합니다. 휴대폰 프레임, 붉은 포인트, 사진, 경력 순서와 문구는 같습니다.

| 항목 | 1안 선명형 | 2안 편안형 |
| --- | --- | --- |
| 글꼴 | Pretendard | Noto Sans KR |
| 본문 | 16px / 1.8 | 17px / 1.85 |
| 경력 보조 정보 | 14px | 14px |
| 제목 | 20px / 700 | 20px / 700 |
| 차이 | 기존 인상 유지, 굵기·자간 정돈 | 더 큰 한글 본문과 카드 내부 여백 |

공통으로 작은 정보의 대비를 높이고, 기술 태그를 한글과 같은 글꼴로 정리했습니다. 실제 폰트 파일 로딩과 계산된 본문 크기를 브라우저에서 확인했습니다.

base.css는 비교를 만들 때의 공개 A2 스타일 사본입니다. 이후 공개 메인의 CSS 변경으로 비교 기준이 달라지지 않도록 고정했습니다. 각 HTML은 동일한 최신 본문을 포함하며, 내비게이션은 기존 스크립트를 사용합니다. Noto Sans KR은 Google Fonts, Pretendard는 기존 CDN을 사용하고 외부 폰트 연결 실패 시 시스템 글꼴로 표시됩니다.

포코펫은 현재 미운영으로 표기하고 설치 링크를 제거했습니다. 과거의 개발·출시 경험은 유지합니다. 운영 종료 시점은 제공받지 않아 임의로 적지 않았습니다.

## 검수

- 두 시안의 본문과 현재 메인의 텍스트 대조.
- 320 / 375 / 768 / 1040px에서 문서·본문 가로 넘침, 44px 메뉴 영역 확인.
- 실제 글꼴 로딩, 제목·본문·보조 정보의 계산된 크기 확인.
- 공개 메인 기존 내비게이션 회귀 검사 통과.
- 로컬 이미지·앵커·파일 참조 검사.
- 실제 브라우저에서 동일한 1040×820 화면의 경력 캡처를 비교 이미지로 사용.
- 실물 기기, Safari, 외부 폰트 차단 환경의 시각 검수는 하지 않음.
