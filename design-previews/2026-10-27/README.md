## 공통 내용

- 오늘한끼 출시 정보와 실제 앱 화면, Google Play 링크.
- NeoFall 실제 플레이 3장과 기존 프로모션 이미지. 두 종류는 캡션으로 구분.
- 기존 경력/담당 업무와 다른 개인 프로젝트 정보 유지.
- 다운로드/성과 수치를 새로 만들지 않음. 기존 NeoFall 1K+ 표기는 원본 이력에서 유지.
- Pretendard와 기존 HTML/CSS 기반. 새 런타임·빌드 도구·패키지 없음.

## 자료 출처

- 오늘한끼: 메인 포트폴리오의 `assets/today-hankki-*.webp` 실제 캡처 재사용.
- NeoFall: 사용자 Downloads의 `neofall1.png`~`neofall3.png` 실제 플레이 화면, `neofall4.png` 프로모션 이미지, NeoFall 프로젝트의 앱 아이콘. 비율을 유지해 WebP로 최적화.
- `preview-*.webp`: 실제 브라우저에서 각 시안을 캡처한 비교용 미리보기.
- A의 프레임/내부 스크롤 코드는 기존 커밋 `8e01bed`를 바탕으로 복원.
